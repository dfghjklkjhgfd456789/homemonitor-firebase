Google Drive Cloud Backup — Access & Sync Instructions
Persistent Storage Active 🟢
How to Access & Connect Google Drive Backup:
  1. In the left navigation sidebar, scroll down to the Storage, Terminal & Admin section.
  2. Click Account Pool & Backup (or navigate to URL hash #/wifi).
  3. At the top of the panel, locate the Google Drive Cloud Database Vault Backup Card:
    • Backup Target: SQLite Database Vault (c2_local_database.db)
    • Last Backup Time: Displays timestamp of last cloud sync.
    • Cloud Storage Status: Shows real-time sync status (Google Drive Ready 🟢 / Synced).
  4. Click the Connect & Sync Google Drive Backup button:
    • Dispatches a native RPC request (drive_backup) over direct WebRTC DataChannel to GoogleDriveBackupEngine.kt.
    • Creates a timestamped local backup snapshot of your SQLite database and telemetry records.
    • Syncs the backup payload to Google Drive Cloud Vault and updates UI metrics live.
